# Quick Deploy — 5 Minutes, One Link

## Step 1: GitHub par code chadhao

1. **https://github.com/new** kholo
2. Repository name: `algo-trading-mvp`
3. **Create repository** pe click karo
4. **"uploading an existing file"** link pe click karo
5. **Sare files drag-drop karo** (purra `algo-trading-mvp` folder ka content)
6. **Commit changes** pe click karo

---

## Step 2: Render par deploy karo

1. **https://render.com** kholo → Sign up (Google se 1 click)
2. **New** → **Web Service**
3. **Connect account** → GitHub connect karo
4. **algo-trading-mvp** repo select karo
5. **Deploy** pe click karo
6. 5–10 min wait karo

---

## Step 3: Link lo

Deploy complete hone ke baad mil jayega:

**https://algo-trading-mvp.onrender.com**

(Service name ke hisaab se URL thoda alag ho sakta hai.)
